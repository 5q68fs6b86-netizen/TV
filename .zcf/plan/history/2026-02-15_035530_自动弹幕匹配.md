# 自动弹幕匹配功能实现计划

## 概要
为 TV 变体播放器添加自动弹幕匹配功能。通过 CF Workers 作为中间层，利用 AI（Qwen 1.5 14B）格式化标题和集数，再调用 danmu_api 进行匹配，获取弹幕 XML URL 交给现有弹幕渲染系统。

## 架构
```
App (vodName + episodeName)
  → CF Worker (AI 格式化 → match API → 返回弹幕 URL)
    → danmu_api (d2.114514heihei.eu.org)
  ← danmuUrl (XML)
App DanmakuOverlay 渲染弹幕
```

---

## 第一部分：CF Worker 代码

### 步骤 1：创建 CF Worker 项目文件
- **文件**：`workers/danmu-match/worker.js`（放在项目根目录下，方便管理）
- **逻辑**：
  1. 接收 POST `{ title, episode }`
  2. 调用 Workers AI `@cf/qwen/qwen1.5-14b-chat-awq` 格式化标题+集数为 match API 所需的 `fileName` 格式
     - prompt 设计：从原始标题（如"庆余年 第二季"）和集数（如"第3集"、"EP03"、"03"）提取纯净标题和 SxxExx 格式
     - 输出格式：`标题 S01E03` 或 `标题 E03`
  3. 调用 `POST https://d2.114514heihei.eu.org/mapiwbhpass/api/v2/match` with `{ fileName }`
  4. 从 match 响应中提取 episodeId
  5. 拼接 `https://d2.114514heihei.eu.org/mapiwbhpass/api/v2/comment/{episodeId}?format=xml` 返回
- **错误处理**：AI 格式化失败时 fallback 直接拼接原始标题+集数
- **预期结果**：Worker 可独立部署到 CF，接收标题集数返回弹幕 URL

### 步骤 2：创建 wrangler.toml 配置
- **文件**：`workers/danmu-match/wrangler.toml`
- **内容**：Worker 名称、AI binding 等配置

## 第二部分：Android 端实现

### 步骤 3：新建 DanmuRepository
- **文件**：`app/src/tv/java/com/fongmi/android/tv/data/repository/DanmuRepository.kt`
- **类**：`DanmuRepository`（@Singleton @Inject）
- **方法**：
  - `suspend fun matchDanmu(title: String, episode: String): DanmuMatchResult`
    - 调用 CF Worker API
    - 解析返回的 danmuUrl
  - `suspend fun searchDanmu(keyword: String): List<DanmuSearchResult>`
    - 调用 danmu_api 的 search 接口（手动搜索用）
- **数据类**：
  - `DanmuMatchResult(success: Boolean, danmuUrl: String, matchInfo: String)`
  - `DanmuSearchResult(animeId: Int, animeTitle: String, episodes: List<DanmuEpisode>)`
  - `DanmuEpisode(episodeId: Int, episodeTitle: String)`
- **常量**：CF Worker 地址硬编码

### 步骤 4：修改 DetailViewModel - 自动匹配
- **文件**：`app/src/tv/java/com/fongmi/android/tv/ui/viewmodel/DetailViewModel.kt`
- **修改**：
  - 注入 `DanmuRepository`
  - 在 `setPlayerStateAndPlay()` 中，异步调用 `danmuRepository.matchDanmu()`
  - 获取到 danmuUrl 后，调用 `playerStateHolder.setPlaybackData(... danmuUrl = url)`
  - 即使匹配失败也不阻塞播放（fire-and-forget 模式）

### 步骤 5：修改 PlayerViewModel - 切集时更新弹幕
- **文件**：`app/src/tv/java/com/fongmi/android/tv/ui/viewmodel/PlayerViewModel.kt`
- **修改**：
  - 注入 `DanmuRepository`
  - 在 `loadEpisodeUrl()` 的 `PlayUrlResult.Success` 回调中，异步调 matchDanmu
  - 获取到 danmuUrl 后，更新 uiState 的 danmuUrl

### 步骤 6：PlayerScreen 手动搜索弹幕
- **文件**：`app/src/tv/java/com/fongmi/android/tv/ui/screens/player/PlayerScreen.kt`
- **修改**：
  - 在顶部控制栏增加"搜索弹幕"按钮（无论是否有自动匹配到弹幕都可用）
  - 点击后弹出 DanmuSearchDialog
- **新建**：`app/src/tv/java/com/fongmi/android/tv/ui/dialog/DanmuSearchDialog.kt`
  - 搜索框 + 结果列表
  - 选择后获取弹幕 URL → 更新 PlayerViewModel 的 danmuUrl

### 步骤 7：PlayerViewModel 增加弹幕相关方法
- **文件**：`app/src/tv/java/com/fongmi/android/tv/ui/viewmodel/PlayerViewModel.kt`
- **新增方法**：
  - `fun searchDanmu(keyword: String)` — 手动搜索
  - `fun selectDanmuEpisode(episodeId: Int)` — 选择弹幕集
  - `fun clearDanmu()` — 清除弹幕
- **新增 State**：
  - `showDanmuSearchDialog: Boolean`
  - `danmuSearchResults: List<DanmuSearchResult>`
  - `isDanmuSearching: Boolean`
