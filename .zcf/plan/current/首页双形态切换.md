# 首页双形态切换实现计划

## 任务概述

实现 TV Compose 首页的双形态切换功能：
1. **TMDB 海报墙模式**：展示热门电影+剧集，点击后聚合搜索并直接播放
2. **站源内容模式**：展示当前站源的推荐内容（现有功能）
3. **模式切换**：点击左侧首页图标弹出对话框切换模式和站源

## 技术方案

- **架构**：统一 ViewModel + 可切换视图层
- **TMDB 数据**：新建 `TmdbRepository.kt`，Kotlin 协程实现
- **状态持久化**：使用 `Setting` 类存储首页模式偏好
- **搜索逻辑**：复用 `VodRepository.searchMultiSite()`

### 步骤 1：新建 TMDB 数据层

#### 1.1 创建 TmdbRepository.kt

**文件**：`app/src/tv/java/com/fongmi/android/tv/data/repository/TmdbRepository.kt`

**功能**：
- 获取热门电影列表 (`/trending/movie/week`)
- 获取热门剧集列表 (`/trending/tv/week`)
- 数据模型转换为统一的 `TmdbItem`

**类/函数**：
```kotlin
@Singleton
class TmdbRepository @Inject constructor() {
    fun getTrendingMovies(): Flow<TmdbResult>
    fun getTrendingTvShows(): Flow<TmdbResult>
    fun getTrendingAll(): Flow<TmdbResult>  // 合并电影+剧集
}

data class TmdbItem(
    val id: Int,
    val title: String,
    val posterPath: String?,
    val backdropPath: String?,
    val overview: String?,
    val releaseDate: String?,
    val mediaType: String  // "movie" or "tv"
)

sealed class TmdbResult {
    object Loading : TmdbResult()
    data class Success(val items: List<TmdbItem>) : TmdbResult()
    data class Error(val message: String) : TmdbResult()
}
```

**预期结果**：可通过 `TmdbRepository` 获取 TMDB 热门内容

## 测试要点

1. TMDB 数据加载正常，海报图片显示正确
2. 点击海报后能正确搜索并找到资源
3. 搜索到结果后能正确导航到详情并自动播放
4. 模式切换对话框正常弹出和关闭
5. 模式切换后 UI 正确更新
6. 站源切换后内容正确加载
7. 首页模式偏好正确持久化
8. D-pad 焦点导航流畅

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| TMDB API 访问受限 | 海报墙无法加载 | 添加错误处理和重试机制 |
| 搜索无结果 | 用户点击海报无响应 | 显示 Toast 提示"未找到资源" |
| 网络延迟 | 用户体验差 | 添加加载指示器和缓存 |
